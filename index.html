PROMPT ENGINEERING

Prompt Lab

Demonstrate how better prompts produce more useful and consistent results.

The 5-part framework

01 · ROLETell the AI who it should act as.
02 · CONTEXTSupply relevant background and audience.
03 · TASKClearly define the desired action.
04 · CONSTRAINTSSet tone, length, rules and limitations.
05 · OUTPUTSpecify the exact format required.

Prompt refinement example

WEAK PROMPT

Write an email asking for more time.

↓ refine with structure ↓
STRUCTURED PROMPT

Role: Professional workplace communication assistant.
Context: Project dependency is delayed.
Task: Request a 2-day extension from the manager.
Constraints: Accountable, concise, respectful.
Output: Subject + 3 short paragraphs + proposed date.

RESPONSIBLE AI

Responsible AI by design

AI should assist human judgment, not replace it.

⚠

Hallucinations

AI can produce incorrect or invented information. Verify important facts.

◌

Bias

Review outputs for unfair assumptions, stereotypes and inappropriate recommendations.

🔒

Privacy

Never paste confidential or sensitive workplace information unless authorized.

✓

Human validation

Review AI-generated content before sending, publishing or making decisions.

Prototype disclaimer

This application uses local deterministic demo logic. It demonstrates the AI workflow and prompt-engineering concepts without pretending that simulated responses are live external AI. A production deployment should connect an approved AI provider through a secure server-side API.

CAPACITI SUBMISSION

Project & Documentation

Everything needed to explain the solution during your presentation.

Problem statement

Professionals spend significant time on repetitive tasks such as drafting emails, summarizing information, planning schedules and conducting research. WorkMate AI consolidates these workflows into one productivity assistant.

Solution overview

A browser-based workplace co-pilot with five task-focused tools, reusable prompt structures and responsible-AI safeguards.

Technology

HTML for structure · CSS for responsive UI · JavaScript for application logic, state, parsing, local storage and interactions.

Production upgrade

Connect the same interface to an approved LLM through a secure backend. Keep API keys server-side, validate inputs and log usage safely.
